# terraform-provider-mailchannels
Terraform provider for the MailChannels Email API (DKIM keys, webhooks, sub-accounts, suppressions).

## Support

This project is supported by the MailChannels team on a best-effort basis. The best way to get support is to file an issue on GitHub: https://github.com/mailchannels/terraform-provider-mailchannels/issues

If you are a MailChannels customer and have a problem with the operation of the MailChannels service, you can get support at https://support.mailchannels.com/
